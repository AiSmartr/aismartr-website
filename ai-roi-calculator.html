How It Works

The Math.

  • Hours returned = people × hours per week × 50 weeks × share automated.
  • Value = hours returned × loaded cost per hour.
  • First-year cost = one-time build + 12 months of run cost.
  • Net value = value − first-year cost.
  • Payback = build cost ÷ (monthly value − monthly run cost).
